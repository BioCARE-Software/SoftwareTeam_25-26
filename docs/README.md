# Docs

Project documentation that explains how the prosthetic arm system works, how to set it up, and why major decisions were made.

- `onboarding/` is for new team member setup and first-week guidance.
- `architecture/` is for system design and subsystem overviews.
- `setup/` is for toolchain installation and build/flash/run steps.
- `decisions/` is for design decision records.
